# 評価用セリフ（かんたん学習の採用判定と、学習タブの各ステップの測定に使う）
# 学習に使う easy_train_lines.txt とは別に持つ。
# 学習した文で評価すると、覚えた文を読ませることになって有利に出るため。
#
# 短文から長文まで、表現を1本ずつ変えて14本。
#   短い（10〜16字）×4 / 中くらい（30〜40字）×5 / 長い（85〜90字・12〜15秒）×3 / 喘ぎ ×2
# 長い文を90字前後で止めるのは、140字を超えると元のモデルでも文の後に
# 声が続くことがあり（実測）、LoRA の差ではなく偶然で値が動くため。
# 測り方（easy_eval.score_lines）:
#   読み間違い = 間違えた字数の合計 / 全体の字数（1本の大崩れはその本の字数で頭打ち）
#   似ている度 = 20字以上の本だけの平均（短い本は声の特徴が安定しない）
#   喘ぎ（🥵 🌬️）は書き起こしが当てにならないので読み間違いに入れない
